Native VictoriaMetrics Operator format (no Prometheus scrape YAML).

These manifests use VictoriaMetrics CRDs:
  - VMStaticScrape  — scrape jobs / targets / relabel / TLS / vm_scrape_params
  - VMAgent         — scrapes selected VMStaticScrape objects and remote-writes

Source parity:
  https://github.com/ydb-platform/ydb/tree/main/ydb/deploy/prometheus
  (all counter URLs and customizations preserved)

Files:
  ydb-staticscrapes.yaml  — one VMStaticScrape per YDB counter group (28 jobs)
  vmagent.yaml            — VMAgent selecting those scrapes

Prerequisites:
  VictoriaMetrics Operator installed in the cluster:
    https://docs.victoriametrics.com/operator/

Apply:
  1) Edit targets in ydb-staticscrapes.yaml
     (storage ports ~8765, database mon ports as in your cluster).
  2) Set remoteWrite.url in vmagent.yaml to your storage
     (VMSingle or vminsert).
  3) kubectl apply -f ydb-staticscrapes.yaml -f vmagent.yaml

TLS:
  Example uses tlsConfig.insecureSkipVerify: true.
  Prefer tlsConfig.caFile / caSecretKeyRef with your YDB CA.

Notes:
  - Labels container=ydb-static|ydb-dynamic and counter=<name> are set on targets.
  - Metric name prefixes and host/instance relabel match the Prometheus example.
  - VictoriaMetrics-only options: vm_scrape_params.stream_parse, max_scrape_size.
